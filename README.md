# SRC TELECOM – Company Profile Website

الموقع التعريفي لشركة **SRC TELECOM (صن رودز)** — اتصالات • كهرباء • تقنية معلومات، الرياض – المملكة العربية السعودية.

صفحة ويب ثابتة (HTML / CSS / JavaScript) بدون قواعد بيانات، تعمل مباشرة على GitHub Pages أو أي استضافة.

## المميزات
- واجهة عربية (RTL) مع زر تبديل للإنجليزية
- عرض تفاعلي لتخصصات الشركة التسعة مع نافذة لنطاق العمل
- منهجية العمل (الاستشارات ← التصميم ← التنفيذ ← التشغيل ← إدارة المشاريع)
- حلول IBS / DAS وأنظمة ELV
- هيكل تنظيمي تفاعلي
- زر واتساب عائم للرقمين: 0500539637 و 0563723792
- نموذج طلب يرسل الرسالة جاهزة عبر واتساب (لا يتم حفظ أي بيانات)
- متجاوب بالكامل مع الجوال

## التشغيل
افتح `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع:
`Settings → Pages → Branch: main → / (root)`

## الهيكل
```
index.html
assets/css/style.css
assets/js/main.js
assets/img/logo-mark.png
```
